How to register an Atlassian OAuth app

  1. Open the Atlassian developer console ↗ and click Create → OAuth 2.0 integration.
  2. In Authorization → OAuth 2.0 (3LO) → Configure, set the callback URL to:
    {% if atlassian_redirect_uri %} {{ atlassian_redirect_uri }} {% else %} https://<your-swarmer-host>/workspaces/{{ ws.id }}/atlassian-oauth/callback (set SWARMER_PUBLIC_URL to see the exact value) {% endif %}
  3. In Permissions, add the Jira API and enable at minimum:
    read:jira-work, write:jira-work, read:jira-user
  4. In Distribution, enable Sharing so other users can authenticate.
  5. Copy the Client ID and Secret from Settings and paste them below.
